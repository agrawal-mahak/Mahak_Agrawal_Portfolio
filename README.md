- 🎨 **Modern Glassmorphism UI**: High-end aesthetic with subtle gradients, frosted glass cards, and micro-animations.
- 🌓 **Dynamic Dark / Light Mode**: Integrated theme toggler with smooth transition state persistence.

- ⚡ **Zero-Dependency Core**: High performance single-page application architecture using native semantic HTML5, CSS3 Variables, and vanilla ES6+ JavaScript.

  - Hero section with live status badge and animated tech stack pills.
  - Interactive Skills Matrix with category filters and proficiency indicators.
  - Featured Projects showcase with interactive modal/overlay triggers and tag filtering.
  - Career Experience timeline.
  - Fully accessible Contact form with live input feedback.
- 🔍 **SEO & Social Sharing Ready**: Configured with complete Open Graph meta tags, structured layout, and fast page performance.

## 🚦 Getting Started Locally

Since this project relies on clean, modern native web technologies, no heavy build steps or npm installations are required!

### Option 1: Direct File Open

Simply double-click `index.html` or `portfolio.html` in your file explorer to open it in your browser of choice.

### Option 2: Using VS Code Live Server (Recommended)

1. Open the repository in VS Code.
2. Install the **Live Server** extension (by Daydey Ritesh).
3. Right-click on `index.html` and select **"Open with Live Server"**.

### Option 3: Local HTTP Server via Node / Python

Using Python 3:

```bash
python -m http.server 8000
```

Then navigate to `http://localhost:8000` in your web browser.
